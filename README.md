# Hotel Management System - Billing Review Service

## Overview
This microservice handles billing, receipt generation, and review management.

## Tech Stack
* Java 17
* Spring Boot
* Maven

## Features / Endpoints
* `GET /api/v1/billing/{reservationId}` - Bill and Receipt Generation
* `POST /api/v1/reviews` - Review Submission
* `GET /api/v1/admin/reviews` - Admin Review Management
